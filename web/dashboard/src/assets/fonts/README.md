# Dashboard fonts

Iftah Sans Arabic, the storefront's design font: IBM Plex Sans Arabic
(© IBM Corp.), subset and renamed by `scripts/build-iftah-sans.py`
(see `internal/modules/storefront/internal/web/assets/fonts/README.md`).
SIL OFL 1.1 (`OFL.txt`). Self-hosted, so the dashboard's CSP keeps
`font-src 'self'`; Vite fingerprints the files at build time.
